# Mark attribution

These marks are typographic wordmarks created for the JitterMap README. None are official logos or trademarks of the named projects or organizations; they exist to label which upstream project a capability depends on without hotlinking a remote icon CDN.

|---|---|---|---|
| rust-wordmark-v1.svg | 1 | Rust programming language | https://www.rust-lang.org/ |
| aws-sdk-rust-wordmark-v1.svg | 1 | AWS SDK for Rust | https://github.com/awslabs/aws-sdk-rust |
| ruvector-rvf-wordmark-v1.svg | 1 | RuVector and RVF (ruvnet) | https://github.com/ruvnet/RuVector |
| metaharness-wordmark-v1.svg | 1 | MetaHarness (ruvnet) | https://github.com/ruvnet/metaharness |

Each file is self-contained inline SVG (no external fonts, scripts, or remote resources) and is versioned by filename suffix; a future revision adds a new `-v2` file rather than mutating this one, so any README referencing `-v1` keeps rendering the same mark.
